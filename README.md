# AZ-5

A browser game dramatising the night of 25–26 April 1986 at Chernobyl Unit 4.
You play Leonid Toptunov, the senior reactor control engineer, taking orders from shift foreman Aleksandr Akimov.

Open `index.html` in a browser (no build step), or serve the folder: `python3 -m http.server`.

- **Left:** the control room. Click the highlighted controls. Hold the rod buttons (or ↑/↓). Space presses the highlighted button.
- **Middle:** a simulated core cut-away with neutrons, Xe-135, steam voids, B₄C absorbers and graphite displacers.
- **Right:** the plant at night.

M mutes. Click the dialogue box to skip a line.
